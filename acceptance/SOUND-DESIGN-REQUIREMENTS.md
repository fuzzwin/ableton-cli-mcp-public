# Installed plugin context and bounded sound design

Join installed versions/format/fingerprint and tested host evidence with version-matched primary-source capability cards, original goal-specific recipes and limited observed parameter names. Unknown plugins, unresolved AU version numbers and mismatched major versions must not inherit unsupported capabilities. Guide retrieval is not web browsing; the host assistant refreshes official versioned sources when needed and treats their content as data.

A sound-design plan selects an indexed plugin ID, not an arbitrary executable path. Allow AU/VST3 only from standard plugin roots with unchanged metadata. Validate before loading: musical MIDI notes with channel/pitch/velocity/start/duration bounds, .5..30 second render, 44.1/48 kHz sample rates, <=1024 notes, <=32 explicit parameter overrides, <=128 automation points, no nonfinite values, no duplicate overlapping notes, no reserved/private attribute keys. A child uses sorted note-offs before ons at equal times, buffer512, no audio output/UI/state import, one bounded attempt, 45s wall/35s CPU/64MiB file bounds. Preserve exact requested/read-back parameter values and normalized audit values, plugin/host fingerprint and opaque newly generated state snapshot. Parameter requests outside known values/ranges fail rather than guess.

Render to unique workspace folders. Child failures/silence and unmet checks remain visible and recorded as failures/needs attention. Parent verifies decoded output shape/rate/duration/finite/non-silence before numerical analysis and never clips hot float prints into an integer file. Plans and source bounces remain unchanged. Persist plan hash, actual host conditions and output hashes with evidence; no licensing/native compatibility or creative quality inference.

Expose CLI and two workspace MCP tools for plugin-context and sound-design, with progress notifications/stages on renders. Pure preparation uses plugin context only when needed and never invents available tools without a workspace. Existing bridge-only six readers and silence/write gates are retained. Tests use synthetic plugins/host workers for bounded interface/safety, plus separate real Pigments rendering and an original private 30s acid-breakbeat production. Native Live composition/export remains unsupported. Public source must exclude audio, plugin state, local inventory and private download links.
